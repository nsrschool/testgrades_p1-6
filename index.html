📖 คู่มือการใช้งาน

สำหรับผู้มาเยี่ยม
  1. กรอก ชื่อ-สกุล, ตำแหน่ง, หน่วยงาน และข้อความความคิดเห็น
  2. ลงลายมือชื่อในกรอบด้วยนิ้ว/ปากกา/เมาส์ (กด "ย้อน" หรือ "ล้าง" ได้)
  3. กด "บันทึกการเยี่ยมชม" รอจนขึ้นหน้าขอบคุณ
รายการเยี่ยม (ผู้ดูแล)
  • ค้นหา / กรองเดือน-ปี ได้ทันที (ข้อมูลอ่านจากเครื่อง)
  • แตะรูปลายเซ็นเพื่อดูขนาดใหญ่
  • 🖨️ พิมพ์รายการเดียว หรือพิมพ์ทั้งหมดที่แสดง เป็น A4 หน้าละ 1 คน (เลือก "บันทึกเป็น PDF" ได้)
  • 📥 ส่งออก .xlsx ตามตัวกรองปัจจุบัน
  • ลบได้เฉพาะ admin
ตั้งค่า
  • แก้ชื่อโรงเรียน/สังกัด/ผู้อำนวยการ/ข้อความ แล้วกดบันทึก — หน้าลงนามเปลี่ยนตามทันที
  • อัปโหลดโลโก้: ระบบย่อรูปอัตโนมัติและเก็บใน Google Drive
  • บัญชีผู้ใช้: admin จัดการทุกอย่าง / staff ดู-พิมพ์-ส่งออก, ใส่รหัสผิด 3 ครั้งจะถูกล็อก (admin ปลดล็อก)
ระบบ (admin)
  • สำรอง .json เก็บไว้เป็นระยะ / กู้คืนเมื่อจำเป็น
  • ล้างรายการเก่าเมื่อขึ้นปีการศึกษาใหม่ (ควรส่งออกก่อน)
ข้อควรรู้เมื่อแก้ไขระบบ
  • แก้ Code.gs → Deploy → Manage deployments → ✏️ Edit ตัวเดิม → New version
  • แก้ index.html → อัปขึ้น Cloudflare Pages ใหม่
